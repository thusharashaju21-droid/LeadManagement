# Lead Management System

A REST API-based Lead Management System developed using **Python, Django REST Framework, and SQLite**.

This project helps manage customer leads by storing customer details, tracking lead status, and organizing lead information efficiently.

## Features

* Add new leads
* View lead details
* Update lead information
* Delete leads
* Manage lead status
* JWT Authentication
* Secure API access

## Technologies Used

* Python
* Django
* Django REST Framework
* Simple JWT
* SQLite
* REST API

## Authentication

JWT-based authentication is used to secure API endpoints. Authenticated users can access authorized lead management operations.

## Purpose

This project was developed to gain practical experience in Django REST Framework, API development, authentication, CRUD operations, and database management.
